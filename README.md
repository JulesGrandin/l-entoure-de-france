# L'entoure de France

Jeu géographique : en cinq manches, tracez sur la carte une zone qui contient environ le nombre d'habitants demandé.

Données : populations municipales Insee 2023, Admin Express COG 2026 (IGN). France métropolitaine.

## Jouer en ligne

https://julesgrandin.github.io/l-entoure-de-france/

## Développement local

```bash
python3 -m http.server 8765
```

Ouvrir http://localhost:8765/

## Données

Les fichiers dans `data/` sont partagés avec le projet [cinquante-cinquante](../cinquante-cinquante/). Pour les regénérer, voir le README de ce projet.
